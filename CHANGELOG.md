# Change Log

All notable changes to the "Vibe Code Explainer" extension will be documented in this file.

## [0.1.0] - 2024-02-12

### Added
- Initial release of Vibe Code Explainer
- Code change detection system
- AI-powered code explanations
- Support for multiple AI providers (OpenAI, Anthropic, Local)
- Diff visualization component
- Learning path tracking
- Session management and summaries
- Integration adapters for Cursor, Windsurf, and Copilot
- Tree view sidebar for changes, learning, and sessions
- Webview panel for rich explanations and visualizations

### Features
- Automatic change detection
- Real-time notifications
- Interactive Q&A about code changes
- Complexity and impact analysis
- Pattern recognition
- Milestone tracking
- Configurable explanation detail levels
